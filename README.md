# 🏥 Hospital Analysis Dashboard - Papollo Healthcare

This project provides a detailed Power BI-based analytical dashboard built on real-world healthcare data from **Papollo Hospitals**. The goal is to extract actionable insights into hospital operations, patient diagnosis trends, billing patterns, and staff feedback.

## 📊 Project Overview

The dashboard visualizes and analyzes data to assist hospital administrators in understanding:

- Patient admission and discharge trends
- Diagnosis frequency and types
- Billing vs. health insurance claims
- Doctor-wise patient feedback volumes
- Bed occupancy by department (ICU, General, Private)
- Monthly trends in hospital operations

## 📁 Files Included

- `Hospital_Analysis.pbix`: Power BI dashboard file
- `Papollo-Healtcare-Dataset.xlsx`: Source dataset used in Power BI
- `Hospital_Analysis.pdf`: Exported dashboard preview for reference

## 💡 Key Insights

- **Diagnosis Distribution**: Viral infections and flu were the most common diagnoses.
- **Feedback Analysis**: Dr. Jay Sinha and Dr. Ravi D received the highest patient feedback volumes.
- **Billing vs Insurance**: Billing amounts often exceed the covered insurance amounts.
- **Bed Occupancy**: General wards showed the highest occupancy trends.

## 📌 Tools Used

- **Power BI**: Data modeling and visualization
- **Excel**: Data cleaning and preprocessing

## 🧩 Dashboard Features

- Interactive filters for patient IDs and date ranges
- Dynamic charts for feedback, billing, and diagnoses
- Insurance vs billing comparison for financial insights

## 📈 Sample Visuals

- Pie Charts, Bar Graphs, Line Charts, and KPI Cards
- Visualized metrics like:
  - Total Billing Amount
  - Occupied Beds
  - Diagnosis frequency
  - Doctor-specific feedback

## 🚀 How to Use

1. Open the `Hospital_Analysis.pbix` file using Power BI Desktop.
2. Ensure `Papollo-Healtcare-Dataset.xlsx` is in the same directory (or relink the data source).
3. Refresh the data model.
4. Explore the insights using filters and visual components.
